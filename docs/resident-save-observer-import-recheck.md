## 直接原因及限定离线修正

同版IronPython 2.7.7.0实际复现：仅在CLR加载同一Core后，原import失败；将**已加载且指纹核验的唯一程序集对象**显式交给公开 `clr.AddReference` 后，import成功。CLR加载不等于IronPython命名空间注册。这解释本次导入失败，不宣称解释所有旧进程异常。

[观察器](../scripts/diagnostics/resident_save_observer.py)的 `load_public_system_instances` 先核对唯一Core和原SHA，再注册该对象，并核对导入类型来自同一程序集。不搜索另一DLL、不访问私有字段；缺失、重复、哈希变化、注册或导入异常及类型来自另一程序集均停止。事件、身份、保存来源及产品保护没有放宽。

**正在运行的诊断固定文件、计划及接收器没有替换；当前unknown没有重试。** 修正只存在于工作分支。
