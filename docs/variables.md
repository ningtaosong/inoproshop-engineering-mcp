# 变量声明只读查询（0.13.0候选）

main已包含codex/variable-inspect的0.13.0候选实现、声明边界修复及旧解析版本续页处理，共二十项工具；原十九项输入输出契约保持，直接从main安装。依据一次受管理IDE读取取得的真实声明做服务端“声明解析”，不是完整原生符号表、编译器语义分析或在线变量采集。没有变量写入、删除、重命名、引用替换或前端表格。

## 输入与读取边界

精确projectId、applicationId及targetKind=application；用户只提供路径/对象名，内部身份由Agent查询。可选objectId限定所属对象；name按变量/字段名称做字面子串筛选，caseSensitive默认false。未给objectId时查询应用支持源码。对象查询首版仍一次读取本Application的现有支持源码，再选择目标解析，实际读取范围在scope中保留，不宣称仅打开了一个对象。

复用现有search固定只读桥接、支持源码枚举和object_read文本规范；没有新原生脚本入口，没有改变任何写入校验。POU支持声明/实现，但本工具只解析声明。现有读取白名单跳过的DUT/声明形式仍不开放为可编辑对象；相关跳过单列，不能当成变量不存在。

## 首版解析语法

- POU的VAR、VAR_INPUT、VAR_OUTPUT、VAR_IN_OUT；GVL的VAR_GLOBAL；结构体DUT的STRUCT字段。结构体字段分类type-field，不能混作变量实例。FUNCTION返回声明分类function-return，不是局部变量；枚举成员和数组DUT定义不作为变量。
- 每条声明支持一个或逗号分隔的多个名称、多行、可选单名称AT地址、类型及可选显式初始化。保留CONSTANT、RETAIN、NON_RETAIN、PERSISTENT修饰词的原文，不推断存储或断电行为。
- 类型支持不展开的基本/命名/限定类型（包括FB实例、自定义类型、命名数组类型），STRING/WSTRING长度及ARRAY [...] OF类型原文。数组变量的声明解析不等于新增ST数组语言能力，也不受数组DUT创建的DINT/0..255产品白名单约束；不计算数组边界、长度或类型语义。
- 初始表达式为边界可确认的原文，支持嵌套圆/方括号及聚合/数组形式；不求值。无显式初始化时hasExplicitInitializer=false、initializerRaw=null，只能说“源码未显式指定”。字段初值、GVL聚合初始化、FB输入初值和运行当前值不能混算，不声称已求出实例全部有效初值。
- 按源码顺序识别代码、//行注释、平衡嵌套块注释、单/双引号字符串，支持$转义和双写引号；字符串内分号/逗号/注释符及注释内引号均不拆分声明。分号仅在已确认的括号层级外结束一条声明，多名称逗号只在名称列表解析。

不可靠的属性、VAR_TEMP/VAR_EXTERNAL等其他声明区、指针/引用、内联复合类型或额外顶层内容返回parse-gap；不为迁就读取扩大写入语法。词法未闭合、括号不匹配或边界不确定时，保留此前完整声明，停止不确定区域及后续对象内容的推测；已确认分号边界的单条不支持声明可留缺口后继续。解析不保证ST编译正确性。

## 条目与原文位置

entries分类为variable、type-field、function-return、comment、parse-gap；counts分别计数，不能把总行数说成变量数。同名局部变量按实际objectId/path分别保留，每项绑定对象contentHash。变量项保留名称、声明区、修饰词、类型原文、显式初始化标记/表达式及可选AT地址。

position覆盖整条声明，namePosition/typePosition/initializerPosition/addressPosition定位各片段，source是该位置对应原文。与object_read一致，仅规范CRLF/CR为LF；偏移从0起、结束不含，行列从1起，均按UTF-16码元计。类型/初始化片段以首末代码词元为边界，内部空白和注释保留；外围注释由comment条目单列。多名称共享整条声明范围，名称位置各自独立，偏移不是删注释或删字符串后的索引。

所有闭合注释作为comment原文及位置保留；仅位于单名称声明内部的注释标为within-single-name-declaration，这是位置关系，不推断注释含义。其他注释标为unassociated；多名称声明内不猜注释独占归属。AT只证明声明中写有地址文本，不是I/O映射核对。

## 完整性、分页与详情

scope保留原对象枚举/读取失败/跳过对象；coverage分开表达对象枚举、原文读取和声明解析。supportedScopeComplete只对应当前支持源码范围，wholeApplicationVariableTable始终false。已知声明对象因不支持形式/位置被跳过时也列入uncoveredDeclarationObjects。无命中且任一覆盖缺口存在，不得宣称工程没有该变量。

默认maxObjects=200、maxEntries=2000，最大2000/10000；达到上限分别标objectsTruncated或page.truncated。条目含注释/缺口等，变量计数单列。limit默认30、最高100，按实际字节可能缩页；只使用返回nextOffset，续页携带expectedVersion及原查询/上限。稳定排序绑定工程、应用、磁盘、对象内容、查询、覆盖状态及解析器版本，不混跨工程或变化后的页。当前parserVersion为declaration-variables-v2；旧v1（含未写此字段的旧记录）在原清单证据可核实时，续页或详情返回VARIABLE_PARSER_VERSION_CHANGED冲突，不自动派发、混页或冻结，调用方须显式发起新的首个查询。缺失、损坏的原清单或不可确认的版本记录继续unknown冻结，不能将证据损坏当成正常升级。

长source、类型、初始化或地址等超过256个UTF-16码元时为明确previews，原字段为null，不等于未初始化或读取失败。用同版本sourceRead:{objectId,offset,limit}读取原始整份声明，外层offset=0，按sourceDetail.nextOffset连续取回，limit最大1024，不启动新IDE。字段预览的长度/摘要属于字段；sourceDetail.totalLength/sha256属于整个声明，先按位置切取字段再核对，不混算。超出元数据返回上限明确unsupported，不静默裁剪或填默认值。

复用工程登记、串行队列、隔离、原操作查询和读取前/关闭后/退出后磁盘哈希保障，不修改、编译或保存，不隐式切换活动工程。服务可持久化原文/查询证据。工程文件与.opt等附属文件分别记录；任务配置、运行变量、I/O和库不由本工具核对。

## 声明边界修正（2026-11-04）

初始读取器会把缺分号后的第二条声明吞进初始化值；内联STRUCT内部字段也可能被误列为外层局部变量；以VAR_开头的命名返回类型被当成声明区。修复前纯内存复现和失败保留，未把负向输入提交IDE。

v2只在初始化外层识别可能的另一声明首部，不全局禁止冒号或赋值符；时间字面量、聚合/数组初始化及括号内命名实参保留原文。遇到该歧义、内联STRUCT/UNION等复合声明、缺END_VAR却进入新声明区时，保留已确认前序声明，以原文位置报告缺口，停止该对象余下解析，不把内部字段或后续作用域猜成当前变量。VAR_TEMP、VAR_EXTERNAL等真实但未支持的声明区仍有缺口；普通VAR_Result、VAR_Local和限定类型My.Type不因前缀或成员拼写被当作关键字。

这是读取边界修正，不是新增内联类型或完整ST语法分析。变量、类型字段、函数返回与注释分类、UTF-16位置、筛选及覆盖报告保持；存在缺口时名称筛选无命中也不能报告确定性不存在。仅variable_inspect结果增加可选版本元数据，原十九项契约、工程写入校验、桥接工厂、比较匹配规则和已验指令均未改。
