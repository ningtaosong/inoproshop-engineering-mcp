## 原生选址证据

- `get_children(False)` 返回原生父节点的直接子列表及顺序。脚本能区分普通设备对象与显式连接器节点。本机 1.9.1.6 暴露 `allowed_interfaces_at(index)`，另有独立的 `insert`、`plug`、`update`。官方脚本接口将 `insert` 定义为按子索引插入。该只读预检结合 `connector_id`、`connector_role`、`interface`、`host_path` 核对目标连接器、匹配方向与可见占用。[设备对象脚本参考](https://content.helpme-codesys.com/en/ScriptingEngine/ScriptDeviceObject.html) · [连接器脚本参考](https://content.helpme-codesys.com/en/ScriptingEngine/ScriptDeviceParameters.html)
- 复用 S6a 只读目录采集得到 729 条安装记录，对照描述的原生子连接器发现 67 个原生描述在某个已观察位置的接口上匹配。空的 `Device/MODBUS_TCP` 在索引 0 允许 `Common.ModbusTcpSerialDevice`，本次目录没有该接口的匹配子描述。候选选择因此转向根设备。
- 目标父设备是 `Device`，GUID `bae96937-5e0e-48a6-8b2a-2ca00576a271`，原生身份 `4102 / 10f4 0002 / 3.5.11.11`。计划位置为 `get_children(False)` 末尾的零基索引 `8`。原生返回允许 `Common.SoftMotion.General` 与 `Common.PCI`。计划只绑定原生 Parent 连接器 ID `0`、接口 `Common.SoftMotion.General`；已观察到的两条直接设备子节点使用 `Common.PCI`，其余为非设备节点。这个候选只说明该夹具的可见拓扑，不提供通用槽位模型。
- 在该候选位置的五条接口匹配中，选择唯一只有一个兼容描述版本的型号 `SMC_FreeEncoder`。精确描述 `1152 / FFFF 0001 / 3.5.5.0`，来自 `System Repository`，厂商 `3S - Smart Software Solutions GmbH`。描述的 Child 连接器 ID `0` 对应同一接口。拟用实例名 `S6bProbeDevice`，只读树里没有重名。目录匹配和初次树读取不能代替当次写入前的身份重读。

## 拒绝边界

8 项离线替身用例通过，包括精确描述身份不唯一、父节点接口不兼容、目标索引或隐式连接器被占用、实例名冲突、预检后树变化及额外兄弟节点检测。它们没有在真实夹具覆盖、删除或试插节点。

后续若再立项，需要先在原生线程内记录各项写前重读及内层异常，确认同一父对象、索引、连接器、描述和占用保持一致。需要单独取得插入、保存关闭重开、兄弟节点及可读配置对照，并对保存版离线编译的证据。读取有限的参数时只报告覆盖范围。现有 `project_compare` 不覆盖设备树和完整设备配置。

探测脚本位于 `scripts/probes/`，只用于独立夹具。产品源文件、初始化指令、版本和 32 项 MCP 契约保持一致。设备添加工具和离线参数写入尚未开发。
