## 选中的是哪一条调用

本机公开的 `IScriptPouObjectCollection.replace(int index, string pou_name, string comment)` 返回 `void`。普通调用列表使用零基索引。安装件中的回调从可写任务的 POUs 列表取出该索引的元素，在同一元素上依次设置名称、注释，外层在回调正常返回后提交。入口和替换回调均没有捕获异常。名称解析、原始注释保留和保存后的持久性需要调用方核对。先前单条移除的例外仍单独保留。[移除探测与诊断](task-call-remove-diagnosis.md)

写前按原生两字段文本记录读取全部调用，绑定工程路径、磁盘 SHA-256、Application、任务、两个目标 PROGRAM 的确定身份及 ST 实现标识。通过同一打开句柄重新读取后，按有序列表找到旧目标、记录检查点，并把该行原始中文注释传给替换方法。本夹具第二行的索引为 1。离线正例另外覆盖了索引 2。[写前守卫](../scripts/probes/task_call_replace_guard.py)
