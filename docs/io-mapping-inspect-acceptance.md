## DSH CLI

Windows 原装 headless CLI 在同一条正式连接收到版本 0.34.0 及全部 37 项工具。一项自然语言任务复用已登记的非空工程。模型两次调用 io_mapping_inspect，按同一版本取回 15 项和 11 项。另有环境、会话、登记、三次结构页查询和三次原状态查询。独立的发现连接得到 server/discover 的 -32601，不参与正式连接核对。

原答复列出的 26 行与持久化工具结果对照，成员、位宽、IEC 地址字段及映射表达式吻合，并说明了方向参照方、自动地址和声明绑定的限制。CLI 会话日志的两个长结果只展示了前缀；两页的完整内容由同一连接的操作编号对应正式结果。答复表头“返回 IEC 地址”对应 manual_iec_address，两个根缺失的字段可在各行的 element.base_type 精确定位。复核包保留原答复。

预检首次将原始正文的末尾换行也计入客户端标题预算，停在任务提交前。按客户端去除首尾空白的口径复核，原始正文 63,009 字节、处理后正文 63,008 字节，加实际服务标题为 63,036 / 65,536 字节。业务任务共发送一次。
