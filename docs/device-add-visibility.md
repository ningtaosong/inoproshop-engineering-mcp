## 方案影响与未验证事项

本夹具在本次编译后可见该节点，无保存重开后不可见。这个序列支持把**打开后、编译前**作为该夹具生成只读追加计划的候选阶段，A、A2、C 的索引 `8` 一致。跨编译阶段不能沿用旧索引；从 B 产生的索引 `9` 不能在 C 复用。结果只覆盖一次固定序列，不能推广为所有 AM610 工程或 OEM 的规则。

写工具仍需要在实际写入句柄上重新验证精确描述、父节点、位置、连接器和可见占用。之后还需从原生读回取得明确的实际挂接归属，并以保存后的重开证据确认新增节点及连接仍在。`allowed_interfaces_at` 的返回只说明该索引可读到的接口条件。本轮没有设备插入、替换、删除、保存、配置写入或在线操作，结论仍限于只读评估。

5 项离线序列测试和 6 项既有跨打开比较测试通过。两次 IDE 均正常退出后，恢复日常 DSH 0.29.0 的原入口，配置、租约和历史记录的指纹核对一致。没有发送模型任务，恢复连接的握手及工具清单未取证。
