探测基线为 main `05ce604a040edd3e3cd053df6a86c8009bed0963`，产品保持 0.31.0、34 项 MCP 工具。此探测使用独立的 AM610 离线夹具，设备描述为 `4102 / 10f4 0002 / 3.5.11.11`，IDE 为 InoProShop 1.9.1.6。

## 方法与写前保护

1. 从已核验的 AM610 最小工程归档提取种子到 D 盘的新目录，使用已有登记、服务租约、源文件租约及隔离检查。固定工程、启动意图和 IDE 的 PID 与创建身份分别留证。
2. 准备根级 ST PROGRAM `PRG_S8Append` 后，读取两份 PROGRAM 的原生类型、嵌入 ST 标识、GUID 和源码哈希，记录唯一 Application、根 Task Configuration、MainTask 和有序调用元组。对这一内存基线执行同步离线编译，当时磁盘仍为种子版本。
3. 在打开句柄内再次核对同一快照、文件哈希、任务字段与完整调用元组。仅当目标唯一且不存在于已有列表时，持久记录派发，再调用一次 `MainTask.pous.add('PRG_S8Append', '')`。离线 guard 测试覆盖大小写重复、元组不完整、已有注释变化和派发记录失败时原生调用次数为零；正例保留非空注释。
4. 即时读取原生元组和解析后的 PROGRAM 身份，核对原列表完整前缀和新增唯一末项。对追加后的内存版本编译，再保存并关闭。等写入 IDE 实际退出，另起 IDE 只读重开、逐项对照保存内容并离线复编。
