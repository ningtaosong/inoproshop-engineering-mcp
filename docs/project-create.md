# 新建最小 AM610 工程（0.17.0 候选）

本分支 `codex/project-create-am610` 扩展至22项工具，仅新增 `project_create`；尚未合并main。已有21项调用保持兼容，登记继续使用v2。新建能力需要客户端实际加载本分支固定构建及Schema，独立握手不等于DSH模型已经接收。

## 使用

自然语言示例：“在 `D:\Example\Demo.project` 新建最小 AM610 工程，编译并保存重开。”路径是需替换的本机示例。模型先查环境、会话、登记，再调用 `project_create({requestId, projectPath})`；内部身份和请求编号由模型处理。目标必须是本机盘符下完整 `.project` 新文件路径，可以创建必要目录。已有文件用 `project_open`，明确要求独立副本才用 `project_open_copy`。

固定预设：AM610-CPU1608TP，设备描述 type4102、id `10f4 0002`、版本 `3.5.11.11`，厂商 Shenzhen Inovance Control Technology。这是本机已安装设备描述，不是PLC固件。Application根下只有一个空ST程序：

```iecst
PROGRAM PLC_PRG
VAR
END_VAR
```

MainTask为周期型，配置20ms、调用PLC_PRG。配置周期不是实测扫描周期。OEM向导还生成库管理器、任务初始化、微分监视等标准支持节点及硬件默认节点，不将其称为完整设备/I/O配置验收。不会预置报警等业务逻辑，也不提供任意设备或任务写入工具。

## 原生方式和文件语义

在InoProShop1.9.1.6初始化后的IDE内，使用已核实的OEM `InovanceProjectWizard.Execute` 五参数原生工厂；传入实际设备描述及ST实现工厂，未复制用户工程或预制业务工程。安装版向导DLL哈希需匹配已验版本；不匹配则拒绝该预设。原生默认任务200ms，初始化时仅将新任务改为20ms并读回。向导创建的InoParamsConfigLib占位符在本机需通过公开 `set_redirection` 指向已安装 `InoParamsConfigLib, 1.0.0.0 (Inovance)`；创建阶段核对解析原文，不下载、安装或修复既有工程的库。

阶段为路径预留、原生初始化、保存并关闭、排他发布指定路径、从该路径重开核对、直接模式登记。为了防止创建与文件出现之间的竞态覆盖，原生初始化文件暂存在该操作IPC证据目录，使用不覆盖的原生File.Copy发布。它是新构造的初始化证据，不是第二份业务工作副本；用户指定路径始终是实际交付和后续编辑对象，不放入数据目录projects下。返回真实路径、Application和直接工程身份；再次project_open同一路径复用身份。

目标文件、占用标记或已有登记存在时拒绝；目录别名要求使用已核实的实际完整路径，不静默改名或重定向。服务锁和路径锁沿用既有机制，外部竞态产生文件时排他发布不会覆盖。初始化失败、超时或保存/退出结果不确定时保留所有文件和阶段证据，停止依赖该身份的修改；同requestId查询/提交返回原操作，不再次创建。running查询原操作，unknown/冲突/冻结不重放、不删锁、不换目录，不自动回滚或删除产物。

新文件不存在创建前工程，创建过程无伪造备份检查点。登记成功后的业务写入继续使用版本校验、真实检查点、去重、冲突检测和读回。新建成功不替代真实编译；按[日常闭环](getting-started.md#日常修改闭环)完成必要读取定位、创建或修改、编译、保存关闭重开、必要复编与目标读回。未要求比较时不调用project_compare。

## 验证记录与边界

原生探测、自动化替身、真实MCP及DSH CLI分别归档，最终结果见本分支验收收尾记录。原生接口成功返回不足以证明预设完整，工具检查真实设备、Application、POU类型/全文、任务周期/调用、新GUID及保存重开身份。设备描述版本不是固件版本，无PLC连接、下载、运行或仿真。

登记v2保持，不允许旧Codex0.14/0.15服务接管；现有0.16固定入口保留，若要调用project_create须在空闲并正常释放服务后加载0.17固定构建。单客户端占用原数据目录，不支持多客户端并行工程操作。历史unknown、11/12回答质量、CmpLog诊断限制、原路径脚本信任、桌面业务/点击和运行验证边界保持，不因本次新建通过而解决。
