## 创建与修改契约

`declaration_create`增加`objectType=array`，沿用精确工程/Application、`parentId=applicationId`、当前`expectedSnapshot`、合法名称与完整同名声明，不接受实现区。示例：

```iecst
TYPE T_DemoValues :
ARRAY [1..3] OF DINT;
END_TYPE
```

仅一维固定长度，元素DINT；上下界显式十进制整数，0<=下界<=上界<=255，最多256项。允许空白和正常ST注释；完整声明以END_TYPE结束，额外TYPE、尾随指令或其他结构拒绝。服务与桥接按源码顺序识别代码、行注释、块注释和单/双引号字符串；注释内引号不跨越已闭合注释，字符串内注释标记不成为注释。支持平衡嵌套块注释；未闭合注释或字符串、游离的块注释结束符拒绝。声明外字符串仍是额外内容，不能被删除后接受。名称沿用原标识符及大小写规则。同名不覆盖或静默改名。拒绝多维、嵌套数组、可变长、表达式或符号边界、其他元素类型、初始化列表、属性、继承及其他别名形式。这是首版产品限制，不是IDE或PLC数组上限。

`code_apply_change`对已识别数组的完整声明使用相同边界，保留名称、原身份和类型，不能转换结构体/枚举/数组；实现省略或空串。输入校验在原生写入前完成，完整ST语法仍由真实编译判断。沿用检查点、去重、版本校验、写后读回、保存重开及unknown冻结，不承诺新的原子事务或自动回滚。

## 原生依据与读取边界

本机InoProShop1.9.1.6实际工厂为`create_dut(name, DutType.Alias, "ARRAY [下界..上界] OF DINT")`。首轮空baseType探测被原生接口拒绝，未保存，原文件未变；一次有据修订后，非零1..3、单元素7..7及最大产品范围0..255分别返回正确默认声明，连接到PROGRAM后两次编译（保存重开前后）均0错误、1条CmpLog警告，身份、父节点、完整声明保留。两次探测原件分开保留，不只展示成功。

原生类型GUID与其他DUT相同，按真实DUT身份加受支持完整声明区分`objectType=array`，不是Structure工厂或普通文本替代。没有独立数组维数、边界或元素类型getter；这些信息来自声明解析，不假称独立属性读取。工厂参数、默认声明、父节点、新GUID和原生类型记录于原IPC `factory.json`。

`object_list/object_read`包含数组类型、完整路径及原身份；只有声明，`hasImplementation=false`、实现为空串。其他不支持的DUT仍跳过，不因有声明就作为可编辑ST。`project_search`支持名称/声明字面搜索，位置对应object_read，命中仅候选引用。`project_compare`沿用Application相对路径+类型匹配，支持数组新增及声明变化，不猜重命名。

旧快照如果明确跳过同路径原生DUT，而新快照识别数组，则报告不可比较及覆盖缺口，不推断新增/删除。原匹配键不变；受此语义影响的比较分页版本标记为array-coverage-v1，拒绝旧页令牌；无数组缺口的既有比较版本及原枚举覆盖语义不变。搜索版本继续绑定实际对象、范围和磁盘状态；不混合跨版本结果。
