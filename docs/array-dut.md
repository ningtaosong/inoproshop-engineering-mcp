# 一维定长数组 DUT（0.12.0候选）

本候选位于`codex/array-dut-create`，main仍为已验0.11.0，尚未合并。扩展现有十九项工具，不新增工具；原POU、GVL、结构体、普通枚举调用兼容。本轮增加的是独立命名数组DUT的工程访问能力，ST变量内数组声明是原有语言能力。

## 创建与修改契约

`declaration_create`增加`objectType=array`，沿用精确工程/Application、`parentId=applicationId`、当前`expectedSnapshot`、合法名称与完整同名声明，不接受实现区。示例：

```iecst
TYPE T_DemoValues :
ARRAY [1..3] OF DINT;
END_TYPE
```

仅一维固定长度，元素DINT；上下界显式十进制整数，0<=下界<=上界<=255，最多256项。允许空白和正常ST注释；完整声明以END_TYPE结束，额外TYPE、尾随指令或其他结构拒绝。名称沿用原标识符及大小写规则。同名不覆盖或静默改名。拒绝多维、嵌套、可变长、表达式或符号边界、其他元素类型、初始化列表、属性、继承及其他别名形式。这是首版产品限制，不是IDE或PLC数组上限。

`code_apply_change`对已识别数组的完整声明使用相同边界，保留名称、原身份和类型，不能转换结构体/枚举/数组；实现省略或空串。输入校验在原生写入前完成，完整ST语法仍由真实编译判断。沿用检查点、去重、版本校验、写后读回、保存重开及unknown冻结，不承诺新的原子事务或自动回滚。

## 原生依据与读取边界

本机InoProShop1.9.1.6实际工厂为`create_dut(name, DutType.Alias, "ARRAY [下界..上界] OF DINT")`。首轮空baseType探测被原生接口拒绝，未保存，原文件未变；一次有据修订后，非零1..3、单元素7..7及最大产品范围0..255分别返回正确默认声明，连接到PROGRAM后两次编译（保存重开前后）均0错误、1条CmpLog警告，身份、父节点、完整声明保留。两次探测原件分开保留，不只展示成功。

原生类型GUID与其他DUT相同，按真实DUT身份加受支持完整声明区分`objectType=array`，不是Structure工厂或普通文本替代。没有独立数组维数、边界或元素类型getter；这些信息来自声明解析，不假称独立属性读取。工厂参数、默认声明、父节点、新GUID和原生类型记录于原IPC `factory.json`。

`object_list/object_read`包含数组类型、完整路径及原身份；只有声明，`hasImplementation=false`、实现为空串。其他不支持的DUT仍跳过，不因有声明就作为可编辑ST。`project_search`支持名称/声明字面搜索，位置对应object_read，命中仅候选引用。`project_compare`沿用Application相对路径+类型匹配，支持数组新增及声明变化，不猜重命名。

旧快照如果明确跳过同路径原生DUT，而新快照识别数组，则报告不可比较及覆盖缺口，不推断新增/删除。原匹配键不变；受此语义影响的比较分页版本标记为array-coverage-v1，拒绝旧页令牌；无数组缺口的既有比较版本及原枚举覆盖语义不变。搜索版本继续绑定实际对象、范围和磁盘状态；不混合跨版本结果。

## 使用流程与验证边界

读取完整支持对象和可读任务，固定无冲突名称与授权文本；首写前capture当前working-copy；创建数组、按需求修改范围，逐项读回；创建使用该类型的PROGRAM并从授权PLC_PRG调用，不修改任务。统一真实编译、保存关闭重开、必要保存版复编、最终全文/任务、最终working-copy capture及完整比较，再实际检索数组。PROGRAM不会自动加入周期任务。

开发端MCP和DSH CLI使用不同正常独立源/受管理副本，结果分别记录，不能用直接MCP或脚本替代DSH模型实际调用。DSH须实际收到0.12.0、十九工具、array Schema与当前指令；独立初始化不代表客户端接收。CLI超时或预览裁剪不等于终态，查询原任务、核对持久化工具消息，不重发写入。`running`查询原操作；unknown、冲突、冻结、额外变化或证据不完整即停止后续写入，保留现场，不删锁、不换目录、不自动回滚。

比较仅覆盖支持源码及实际可读任务配置，不包含设备参数、I/O或其他非ST配置。未连接PLC、下载、运行或仿真；源码初始化、合法索引及求和的编译不证明实际计算结果、执行顺序或越界保护。CmpLog警告及影响保留，不自动添加库消除。CLI不是桌面同会话、界面或链接点击验收。历史11/12质量未通过、答复展示问题、原unknown/隔离、旧锁和旧失败保持。

当轮实际构建/测试、两套工程操作、原答复、首败、比较及检索以本地复核包为依据；[Schema](tool-schemas.json)、[入门文档](getting-started.md)及[工作指令](../instructions/inoproshop-workflow.md)分别提供机器契约、接入入口和Agent流程。
