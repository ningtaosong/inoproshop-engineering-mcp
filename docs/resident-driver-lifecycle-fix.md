## 验收驱动入口

- `scripts/resident-acceptance-driver.mjs start CONFIG`：固定入口必须提供绝对路径、SHA-256、工作目录、原登记目录、预期版本及完整工具名。新诊断输出目录不等于新登记目录。初始化不打开工程。
- `submit DIRECTORY PLAN`：单独的明确提交。PLAN包括`kind`（open或edit）、独立id及authorization记录；edit使用实际objectId和授权前后完整实现区原文，声明原样传回。控制文件不能提前排好下一轮。
- `finish DIRECTORY REFERENCE`：停止新业务，向自有SDK子服务发送一次EOF并有界观察；从不调用工程保存、关闭或退出。IDE还活着时保留`finish-pending`，不杀进程。
- `observe-exit DIRECTORY REFERENCE`：只追加有界迟到退出观察，不重发EOF，不抹去首次关闭期限错误。

发生业务失败仍保留finish控制。原运行中的旧driver没有上述入口，修改磁盘文件不能更改其内存；禁止调试注入或另一服务接管。当前新驱动不是GUI、Agent框架或产品MCP工具。
