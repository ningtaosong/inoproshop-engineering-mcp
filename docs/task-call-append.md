# 已有周期任务末尾追加一个 PROGRAM

0.32.0 功能分支候选新增 `task_call_append`，共 35 项工具。原生依据为探测提交 `822d757e15513e305a22f3c16b017e0dcdb05bf9`。

范围为已验设备描述 `4102 / 10f4 0002 / 3.5.11.11`、已有普通 Cyclic 任务、同一 Application 的一个已有且唯一根级 ST PROGRAM。调用名称和注释必须完整可读。识别不到名称形式或出现同名限定项时保守拒绝。非空已有注释逐项保留。替换、删除和重排另行探测。

`task_inspect` 提供 `taskId`、`configurationVersion` 和 `diskHash`。用 `project_structure` 取得目标任务的父配置节点，`object_read` 取得根级 PROGRAM 定义的 `objectId` 和 `contentHash`。用户只需提供工程、任务名和程序名。

同一打开句柄内再查完整调用顺序和版本，确认 PROGRAM 原生 ST 标识。建立检查点，留存派发记录，只调用一次原生 `pous.add(程序名, '')`。`before`、`afterAppend` 和 `after` 中保留写前、写后及重开的原生任务配置。原列表须逐项构成新列表的完整前缀，新增末项与 PROGRAM 唯一绑定。原任务字段、其他任务和支持的源码快照保持一致。

成功后编译保存版，按需保存重开并对最终磁盘版本复编、读回。编译证据应绑定新的任务配置版本。重复请求复用原操作；目标已经存在或证据过期时停止。写后不确定返回 `unknown` 并冻结，保留检查点和原异常。调用顺序来自离线工程配置，运行与实际调度未测。
