# S4b：普通结构体 DUT 新增单个字段

功能分支 `codex/struct-field-add`，基线 main `55bb58fc97b266215ad536b6b0f9d4f66c80670f`。候选0.39.0／38项工具；尚未合并、部署或发布。真实验收记录将在完成后单独追加，当前不得将离线替身结果写成真实IDE通过。

## 限定能力和使用

扩展 `variable_edit` 的 `add-struct-field`。精确对象为当前Application根节点的普通结构体DUT；原生DUT类型ID `2db5746d-d284-4425-9f7f-2663a34b0ebc` 加完整 `TYPE … STRUCT … END_STRUCT END_TYPE` 原文确认种类，未取得独立DUT子类型getter。

只增加一个无初值的 BOOL、DINT 或 TIME 字段。结构体须完整、非空；既有字段须为唯一普通单字段，也限BOOL／DINT／TIME；既有显式初值须符合现有字面量规则（DINT -2147483648..2147483647；TIME 0..60000ms的T#整数ms/s；BOOL TRUE/FALSE）。名称遵守既有关键字、内建运算符和大小写冲突规则。拒绝共享字段声明、属性修饰、AT、嵌套、数组、联合、库类型、空或不完整声明。这个保守范围不表示所有普通结构体均支持。

用户只需指定工程、结构体和新字段名称／类型。示例：“只给指定工程的 ST_Config 增加 BOOL 字段 Enable，不设初值；保留原字段和实例源码，编译、保存重开并读回。”Agent查询内部对象及版本。动作不接收initializer、section、成员初值或旧值参数；不改类型、不删除或重命名字段、不重写现有聚合初始化。

## 原文、身份和异常保护

服务在队列内完整重读DUT并做词法／声明规划；桥接在实际写入句柄独立核对根归属、唯一名称、原生身份、完整结构声明、源码／磁盘版本及完整状态摘要。只在可信END_STRUCT边界插入一行或内联片段，按UTF-16位置对应原生文本，保留其余原文和CRLF／CR／LF、中文、注释与空白；不排序或重建字段。

新增前、即时及保存重开后采集所有可读取文本对象的原生身份、路径、嵌入实现类型和完整原文，以及选定Application的任务配置和调用行。源码对象目录按唯一objectId、任务集合和PROGRAM目录按现有唯一身份核对；任务内调用名称、备注及顺序严格比较。类型实例及调用的源码作为原文保留，未声称取得全工程语义引用或运行布局兼容证明。缺失、重复、读取失败、覆盖不完整或额外变化拒绝；不把不同值／null／空串合并。

实际快照和差异先发布，再校验。服务独立重复规划、核对最小插入和前／即时／重开状态，重启查询仍用持久化原请求及证据。沿用原工程保护、检查点、去重、可信退出和unknown冻结。直接编辑及旧副本模式均不自动反向修改、回滚或恢复性保存；保存或发布失败保留首错和清理异常。新动作不改变既有隔离观察、退出保护或其他工具。
