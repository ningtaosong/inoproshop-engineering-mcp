# S4a 变量级编辑（开发分支候选）

`variable_edit` 以 `add` 或 `set-initializer` 为动作，服务在受管理队列内重新读取目标声明，再生成插入单条声明或替换显式初始化值的最小源码差异。它沿用完整对象哈希、工程快照、磁盘哈希、写前检查点、请求去重、保存关闭重开及读回。调用者提供精确 Application 和对象身份；用户只需说明工程和目标。

首版只接受普通 ST PROGRAM／FUNCTION／FUNCTION_BLOCK 的 `VAR` 局部声明，以及 Application 根 GVL 的 `VAR_GLOBAL`。新增必须给出 `BOOL`、`DINT` 或 `TIME` 类型及初值。BOOL 为 `TRUE`／`FALSE`，DINT 为 -2147483648..2147483647 的规范十进制整数，TIME 候选语法为非负整数 `T#...ms`／`T#...s`，暂限 0..60000 ms；本机原生边界仍待验收，不能据此宣称厂商允许范围。

现有变量仅替换一个已明确声明的显式字面初值。联合声明、多个合适声明块、无显式初值、特殊修饰、AT、结构体聚合成员、数组元素、访问器内变量、类型或名称修改均拒绝。变量表是源码声明解析，不是原生符号表、语义引用分析或运行变量采集。

编译、保存和目标读回仍须按任务执行；本工具写后保存重开不代替编译。默认流程不采集比较基线。当前分支的自动化夹具通过不构成真实 IDE 或 DSH CLI 验收，交付前仍须分别取证。
